# Продажи товаров

Интерактивный отчёт по продажам за 02.10–02.11.2026.

Сайт: https://bositkhan.github.io/product-sales/

## Возможности

- Топ-10, топ-20 и топ-30 товаров.
- Продажи по видам товаров с выбором категории.
- Поиск по названию, коду и штрих-коду.

Отчёт работает в браузере без регистрации. Данные встроены в `index.html`; это снимок за указанный период. Фильтры и поиск работают у каждого посетителя отдельно, изменения общих данных через сайт не предусмотрены.

## Продажи по складам

Дашборд по выгрузке «Анализ продаж по складам» из REGOS (10.11.2026): склады, группы, топ товаров, тепловая карта товар × склад, таблица всех товаров с фильтрами и поиском.

Сайт: https://bositkhan.github.io/product-sales/sklady/

Фильтры сохраняются в ссылке, так что можно отправить ссылку сразу на нужный склад или группу.

## Обновление

Замените `index.html` новой версией отчёта и отправьте изменения в ветку `main`. GitHub Pages публикует сайт из корня этой ветки.

Для локального просмотра откройте `index.html` в браузере.
